# CKAD Lab: Observability

**Status: Not started**

Part of hands-on CKAD prep (KodeKloud labs). Maps to course section: Observability (18% of the CKAD exam).

## Planned topics

- Liveness, readiness, and startup probes
- Container logging (`kubectl logs`, including multi-container and previous instances)
- Monitoring applications (`kubectl top`, metrics)
- Debugging Pods and containers (`describe`, events, `exec`)
- API deprecations

## Format

Lab writeups will be added here as they are completed, following the layout used in [Core Concepts](../01-core-concepts): a `README.md` per lab (problem, solution, outcome, commands I got wrong), with `manifests/` for the YAML used and `screenshots/` for terminal output or diagrams.
